The shortcuts, by where they work.

## Anywhere
- `?` — Help for this screen
- `⌘?` — Keepr Help
- `⌘1` — Backup Plans
- `⌘2` — Restore
- `⌘3` — Activity
- `⌘4` — Destinations
- `⌘,` — Settings
- `⌘K` — Find a file in any backup
- `⌘N` — New plan
- `⌘B` — Back up every plan now
- `⌘[` `⌘]` — Back, forward
- `Esc` — Close the help or a sheet

## Restore
- `←` `→` — Earlier, later snapshot
- `Space` — Quick Look the picked file
- `⌘ click` — In the size map, find a folder in Files

## Menu bar panel
- `⌘B` — Back up all now
- `⌘R` — Restore a file
- `⌘O` — Open Keepr
- `⌘,` — Settings
- `⌘Q` — Quit Keepr
- `Esc` — Close the panel
