The shortcuts, by where they work.

## Anywhere
- `?` — Help for this screen
- `⌘?` — Keepr Help
- `⌘1` — Backup Plans
- `⌘2` — Size Map
- `⌘3` — Restore
- `⌘4` — Activity
- `⌘5` — Destinations
- `⌘,` — Settings
- `⌘K` — Find a file in any backup
- `⌘J` — Ask
- `⌘N` — New plan
- `⌘B` — Back up every plan now
- `⌘[` `⌘]` — Back, forward
- `Esc` — Close the help, Ask or a sheet
- `⌘Q` — Quit Keepr (asks first)

## Restore
- `←` `→` — Earlier, later snapshot
- `Space` — Quick Look the picked file
- `⌘ click` — In the size map, find a folder in Files

## Size Map
- `⌘ click` — Open a folder in Restore

## Menu bar panel
- `⌘B` — Back up all now
- `⌘R` — Restore a file
- `⌘O` — Open Keepr
- `⌘,` — Settings
- `⌘Q` — Quit Keepr (asks first)
- `Esc` — Close the panel
