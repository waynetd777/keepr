The shortcuts, by where they work.<!-- windows --> On Windows, Ctrl takes the place of the Mac's Command key.<!-- /windows -->

## Anywhere
- `?` — Help for this screen
- `⌘?` — Keepr Help
- `⌘1` — Backup Plans
- `⌘2` — Size Map
- `⌘3` — Restore
- `⌘4` — Activity
- `⌘5` — Destinations
- `⌘,` — Settings
- `⌘K` — Find a file in any backup
- `⌘J` — Ask
- `⌘N` — New plan
- `⌘B` — Back up every plan now
- `⌘[` `⌘]` — Back, forward
- `Esc` — Close the help, Ask or a sheet
<!-- mac -->- `⌘Q` — Quit Keepr (asks first)<!-- /mac -->

## Restore
- `←` `→` — Earlier, later snapshot
- `Space` — <!-- mac -->Quick Look the picked file<!-- /mac --><!-- github --> (on Windows: <!-- /github --><!-- windows -->Open the picked file's version in its app<!-- /windows --><!-- github -->)<!-- /github -->
- `⌘ click` — In the size map, find a folder in Files

## Size Map
- `⌘ click` — Open a folder in Restore
