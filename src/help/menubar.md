Closing the window doesn't quit Keepr: <!-- mac -->it leaves the Dock and keeps backing up from the menu bar.<!-- /mac --><!-- windows -->it keeps backing up from the notification area, at the right of the taskbar (under the ^ when Windows tucks icons away).<!-- /windows -->

## The icon
Keepr's icon in the <!-- mac -->menu bar<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->notification area<!-- /windows --><!-- github --> (Windows)<!-- /github --> shows a dot while it's backing up, and a mark when a plan needs attention.

## The panel
Click the icon<!-- windows --> (either button)<!-- /windows --> for whether everything is kept, the backup that's running with its time left, and each plan's last and next backup or its problem. Click a plan to open Keepr.<!-- windows --> From a taskbar at the foot of the screen the panel opens above the icon.<!-- /windows -->

## Its menu
**Back up all now** (`⌘B`), **Pause backups for an hour** (which also stops the backup that's running), **Restore a file…** (`⌘R`), **Open Keepr** (`⌘O`), **Settings…** (`⌘,`)<!-- windows -->, **Keepr Help**, **Check for Updates…**<!-- /windows --> and **Quit Keepr** (`⌘Q`), which asks first, and says so if a job is running. <!-- mac -->Quit Keepr, here or in the Keepr menu, is the way to stop it backing up. Quit in the Dock quits straight away, without asking.<!-- /mac --><!-- windows -->Quit Keepr here is the way to stop it backing up: Windows has no Keepr menu.<!-- /windows -->

## Open at Login
The switch above Open Keepr is the same as [Open at Login](app:settings) in Settings: it starts Keepr in the <!-- mac -->menu bar when you log in<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->notification area when you sign in<!-- /windows --><!-- github --> (Windows)<!-- /github -->. It's only there in the installed app.
