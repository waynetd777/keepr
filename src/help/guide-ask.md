## Ask what takes the space
Open [Size Map](app:sizemap) and click a big folder to zoom into it, then click **Ask** in the path bar above either map. The question is typed in for you, with what's in that folder; change it if you like and press Return. **Ask** in the toolbar (`⌘J`) takes any question.

## Read the answer
The answer comes from an AI tool signed in on this Mac, working from Keepr's figures and folder names, never your files. It says what each big folder is likely to be and whether it needs backing up. The [Ask help](help:ask) lists exactly what's sent, and [Settings](app:settings) turns Ask off.

## Check a suggested change
If leaving something out would help, the answer ends with a suggested change to the plan. Before you apply it, the card shows the settings before and after, how much of the latest backup it would leave out, and warnings about anything that changed this week or that tools don't rebuild. Click **Apply** to save it; the plan on [Backup Plans](app:overview) has it from the next backup.

## Undo it if you need to
Each change made with Ask is in [Activity](app:activity) as a **Plan change**. Click it, then **Undo**, to put the plan back as it was.

## Ask about a run
When a backup fails or stores more than you expected, click it in [Activity](app:activity) and click **Ask** under its log. The question goes with the run's message and the end of its log.
